### R1 ✅ 控制面 watch 无心跳，静态配置下 server 自判过期并拒绝新连接

- server：新鲜度只在 `duotunnel-server/control/control_client.rs:394/604/679/785` 刷新，全部依赖收到事件；阈值 `runtime/health.rs:7-9` = 60s 降级 / 120s 安全过期 / 300s 过期。
- 后果：配置长期不变时，**120s 后新 tunnel client 认证被拒（`ingress/handlers/quic.rs:252`），300s 后所有新公网连接被拒、`/healthz` not ready**。
- 连带：`recv_config_event` 无读超时、TCP 无 keepalive，ctld 半开死亡时 server 永不察觉。
- 修复：watch 协议加 Ping/Pong（或周期 Duplicate 快照，间隔 < 30s）；server 端读超时即重连。
